\section*{Introduction}

This document showcases \texttt{pullquote.sty}, the standalone LaTeX
distribution of the \texttt{pullquote} environment for documents
compiled directly with (pdf/Xe/Lua)LaTeX, without Pandoc or Quarto.
Each example below mirrors one in \texttt{test/pullquote-examples.md}
(the Pandoc/Quarto specimen), translated from \texttt{pq-*} attributes
to the \texttt{.sty}'s own \texttt{width}, \texttt{color}, \texttt{size},
\texttt{skip}, \texttt{align}, \texttt{boxalign}, \texttt{barwidth},
\texttt{barcolor}, and \texttt{padding*} keys, so both specimens
exercise the same feature set and stay easy to compare side by side.

\textbf{Engine Note:} compile with \texttt{lualatex} or \texttt{xelatex}
(what \texttt{make docs} uses) for font parity with the other three
specimens — Noto Serif, Noto Sans, and Fira Mono, all loaded via
\texttt{fontspec} below. \texttt{pdflatex} still compiles this document,
but silently falls back to Computer Modern throughout, since
\texttt{fontspec} isn't available on that engine.

\textbf{Installation Note:} place \texttt{pullquote.sty} on your
\texttt{TEXINPUTS} or alongside your document, then load it with
\texttt{\textbackslash usepackage\{pullquote\}}.

\section*{Basic Example}

Ordinary paragraph text before the pullquote, to show how it breaks the
flow of the page.

\begin{pullquote}
"Typography is the craft of endowing human language with a durable visual
form." --- Robert Bringhurst
\end{pullquote}

Ordinary paragraph text after the pullquote. The keys below match the
\texttt{tcolorbox}-backed environment defined in \texttt{pullquote.sty}:
\texttt{width}, \texttt{color}, \texttt{size}, \texttt{skip},
\texttt{align}, \texttt{boxalign}, \texttt{barwidth}, \texttt{barcolor},
and \texttt{paddingleft}\slash\texttt{paddingright}\slash%
\texttt{paddingtop}\slash\texttt{paddingbottom}.

\subsection*{Font Sizing}

There's no named size scale in LaTeX the way \texttt{pq-size}
provides one (\texttt{3xs} through \texttt{3xl}) — the \texttt{size} key
just takes a raw font-switching command, so the scale below is spelled
out using the same LaTeX commands \texttt{pullquote.lua} would emit for
each named step, plus \texttt{\textbackslash fontsize\{\}\{\}\textbackslash selectfont}
for an arbitrary point size.

\begin{pqcode}
\begin{verbatim}
\begin{pullquote}[size=\Large\itshape\rmfamily]
...
\end{pullquote}
\end{verbatim}
\end{pqcode}

\begin{pullquote}[size=\normalsize\itshape\rmfamily]
\textbf{m:} Medium (base document size).
\end{pullquote}

\begin{pullquote}[size=\large\itshape\rmfamily]
\textbf{l:} Large (the .sty's default size).
\end{pullquote}

\begin{pullquote}[size=\Large\itshape\rmfamily]
\textbf{xl:} Extra Large.
\end{pullquote}

\begin{pullquote}[size=\LARGE\itshape\rmfamily]
\textbf{2xl:} Extra Extra Large.
\end{pullquote}

\begin{pullquote}[size=\huge\itshape\rmfamily]
\textbf{3xl:} Extra Extra Extra Large.
\end{pullquote}

\begin{pullquote}[size=\fontsize{24pt}{28.8pt}\selectfont\itshape\rmfamily]
\textbf{24pt:} Custom arbitrary point size.
\end{pullquote}

\subsection*{Font Weights, Shapes, and Families}

\begin{pqcode}
\begin{verbatim}
\begin{pullquote}[size=\large\bfseries\itshape\rmfamily]
This paragraph is in bold weight.
\end{pullquote}
\end{verbatim}
\end{pqcode}

\begin{pullquote}[size=\large\bfseries\itshape\rmfamily]
This paragraph is in bold weight.
\end{pullquote}

Pullquotes render in italics by default; \texttt{\textbackslash upshape}
overrides that back to upright.

\begin{pullquote}[size=\large\upshape\rmfamily]
This paragraph is explicitly rendered upright (non-italicized).
\end{pullquote}

\texttt{\textbackslash rmfamily}\slash\texttt{\textbackslash sffamily}\slash%
\texttt{\textbackslash ttfamily} match the same
serif/sans/mono families \texttt{pq-family} resolves to across every
format:

\begin{pullquote}[size=\large\itshape\rmfamily]
This paragraph is in serif.
\end{pullquote}

\begin{pullquote}[size=\large\itshape\sffamily]
This paragraph is in sans-serif.
\end{pullquote}

\begin{pullquote}[size=\large\itshape\ttfamily]
This paragraph is in monospace.
\end{pullquote}

Any other font name is a literal, applied directly via
\texttt{\textbackslash fontspec} (XeLaTeX/LuaLaTeX only) instead of going
through \texttt{\textbackslash rmfamily}\slash\texttt{\textbackslash sffamily}\slash%
\texttt{\textbackslash ttfamily}:

\begin{pullquote}[size=\large\itshape\PQCustomFont]
This pullquote uses a specific display font, independent of the
document's main font.
\end{pullquote}

\subsection*{Colors and Borders}

Named SVG colors (loaded via \texttt{xcolor}'s \texttt{svgnames}
option) work directly as \texttt{color}\slash\texttt{barcolor} values;
\texttt{barwidth} adjusts the left border's thickness. A \texttt{rem}
value from the Pandoc specimen becomes the same number of \texttt{em}
here, since both LaTeX and Typst resolve \texttt{em} natively against
the current font size.

\begin{pqcode}
\begin{verbatim}
\begin{pullquote}[color=CadetBlue, barcolor=Thistle, barwidth=0.5em]
...
\end{pullquote}
\end{verbatim}
\end{pqcode}

\begin{pullquote}[color=CadetBlue, barcolor=Thistle, barwidth=0.5em]
This quote uses the SVG named color \textbf{CadetBlue} for text and the
pastel \textbf{Thistle} for a thick 0.5em border.
\end{pullquote}

\texttt{paddingleft} controls the gap between the bar and the text,
independent of the bar's own thickness:

\begin{pullquote}[barwidth=0.5em, paddingleft=1.5em]
This quote widens the gap between the bar and the text using
\textbf{paddingleft=1.5em}, independent of the 0.5em bar thickness.
\end{pullquote}

The remaining three sides — \texttt{paddingright}, \texttt{paddingtop},
and \texttt{paddingbottom} — can each be tuned independently:

\begin{pullquote}[barcolor=SeaGreen, paddingleft=1em, paddingright=1em, paddingtop=1em, paddingbottom=1em]
This quote sets an even 1em of padding on every side, giving the text
room to breathe on all edges rather than just next to the bar.
\end{pullquote}

6-digit and shorthand 3-digit hex codes both work, via
\texttt{\textbackslash definecolor\{...\}\allowbreak\{HTML\}\allowbreak\{...\}} plus a
\texttt{color}\slash\texttt{barcolor} key naming the defined color (see the
preamble above):

\begin{pullquote}[color=pqHexText, barcolor=pqHexBar]
This quote uses raw Hex codes: \textbf{\#827397} for text and the
shorthand \textbf{\#FAA} (Soft Coral) for the bar.
\end{pullquote}

\texttt{xcolor}'s percentage-mixing syntax (\texttt{Color!pct!Color})
works directly in \texttt{color}\slash\texttt{barcolor} — the same syntax
\texttt{pullquote.lua} passes through unchanged for LaTeX output:

\begin{pullquote}[color=Indigo!90!Black, barcolor=Indigo!20, barwidth=0.375em]
This quote uses a three-part blend for the text (\textbf{Indigo mixed
at 90\% with Black}) and a standard two-part blend with white for the
bar.
\end{pullquote}

\subsection*{Block-Level Positioning and Width}

\texttt{width} and \texttt{boxalign} position the pullquote block
within the page; \texttt{boxalign} takes \texttt{tcolorbox}'s own
keywords (\texttt{flush left}, \texttt{center}, \texttt{flush right})
rather than \texttt{pq-box-align}'s left/center/right.

\begin{pullquote}[width=0.45\linewidth, boxalign=flush right]
This quote takes up 45\% of the page width and is aligned flush to the
right margin.
\end{pullquote}

\subsection*{Inner Text Alignment}

\texttt{align} controls text alignment \emph{within} the box — the same
\texttt{\textbackslash raggedright}\slash\texttt{\textbackslash centering}\slash%
\texttt{\textbackslash raggedleft} commands \texttt{pq-text-align} resolves
to for LaTeX — independent of \texttt{boxalign}, which positions the
box itself:

\begin{pullquote}[align=\centering, width=0.7\linewidth, boxalign=flush left]
This quote takes up 70\% of the page and is aligned to the left margin,
but the text \emph{inside} the box is centered.
\end{pullquote}

\subsection*{Interline Spacing (Line-Height)}

\texttt{skip} sets \texttt{\textbackslash baselineskip} directly, rather
than acting as a multiplier the way \texttt{pq-skip} does — so the
\texttt{pq-skip="2.0"} equivalent below is spelled out as \texttt{2em},
matching what \texttt{pullquote.lua} itself emits for that same value:

\begin{pullquote}[size=\Large\itshape\rmfamily, skip=2em]
This quote uses a 2em baselineskip, doubling the interline spacing to
let the text breathe.
\end{pullquote}

Tightening works the same way, with one caveat that is LaTeX's rather than
this package's: TeX will not set a \texttt{\textbackslash baselineskip}
below the natural line height, so it falls back to
\texttt{\textbackslash lineskip} and quietly clamps values much under
\texttt{1.2em}. The HTML and Typst pathways honour them instead.

\begin{pullquote}[size=\large\itshape\rmfamily, skip=1.15em]
This quote is deliberately tight, to show how far the lines can be pulled
together before an engine stops following.
\end{pullquote}

An explicit length behaves the same as it does in the filter: an
\texttt{em} value scales with the pullquote's own font size, so it stays
proportional as \texttt{size} changes.

\begin{pullquote}[size=\large\itshape\rmfamily, skip=1.6em]
This quote sets its interline spacing as an explicit 1.6em length rather
than a bare multiplier.
\end{pullquote}

\subsection*{Global Configuration}

There's no document metadata for a LaTeX \texttt{\textbackslash pullquote}
to fall back to, but \texttt{\textbackslash pqsetdefaults} is the same
idea: redefine it once, and every un-keyed \texttt{\textbackslash pullquote}
after that point picks up the new project-wide defaults automatically.

\begin{pqcode}
\begin{verbatim}
\renewcommand{\pqsetdefaults}{%
  \def\pqcolor{DarkSlateGray}%
  \def\pqbarcolor{CadetBlue}%
  \def\pqwidth{0.8\linewidth}%
  \def\pqboxalign{center}%
  \def\pqsize{\large\itshape\rmfamily}%
  \def\pqskip{\baselineskip}%
  \def\pqalign{\raggedright}%
  \def\pqbarwidth{4pt}%
  \def\pqpaddingleft{12pt}%
  \def\pqpaddingright{0pt}%
  \def\pqpaddingtop{4pt}%
  \def\pqpaddingbottom{4pt}%
}
\end{verbatim}
\end{pqcode}
